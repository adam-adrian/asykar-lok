Beranda Klasemen Turnamen Event

Koreksi yang Baru Diterapkan:

  • Kalibrasi Lebar Frame: Simulator mobile disetel ke box-sizing: content-box agar layar dalam benar-benar berukuran 375px (sebelumnya terpotong oleh border frame 20px).
  • Flexbox Anti-Overflow: Menambahkan min-width: 0 pada brand kiri dan flex-shrink: 0 pada kluster kanan, sehingga tombol akun tidak akan pernah terdorong keluar layar.
  • Optimasi Dot Sync HP: Menghapus padding pill berlebih di mobile, hanya menyisakan dot 7px murni.
  • Ukuran Pill Terukur: Avatar 20px, gap 5px, dan max-width: 65px untuk nama akun, pas dan proporsional.
